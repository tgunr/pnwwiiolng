========================================================================
    ExeSum : Project Overview
========================================================================

PRIVATE: CRS Internal Use Only - NOT FOR REDISTRIBUTION OR OFFISTE USE

This application generates a 64bit checksum for a WW2.EXE binary.

Checkums is output in 3 formats simultaneously:

1- It is printed to standard output incase you wish to use it as part of a script
2- It is writen to "exesum.txt"
3- It is copied to the windows clipboard (so you can paste with ctrl-v)

The checksum is for CRS use only and is not to be issued to customers.

You should supply the generated checksum to the patch manager or via the
http://kfsone.playnet.com/ >> Admin >> Checksums tool.
