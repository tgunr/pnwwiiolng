Modalita' di installazione di NVFoil 1.01

1) Copiare il file nvfoil.zip in una directory temporanea, per esempio
c:\temp
2) Scompattare il file nvfoil.zip con una opportuna utilita' come pkunzip,
winzip, swunzip, etc.
3) Dal File Manager o da Gestione Risorse, lanciare il file setup.exe e
seguire le istruzioni ivi contenute.
4) Al termine dell' installazione, saranno inoltre presenti nella directory
"airfoils"i profili del database dell' universita' dell' Illinois Urbana-
-Champaign.

Per ulteriori informazioni, consultate la pagina web
http://www.geocities.com/CapeCanaveral/Hangar/2524/nvfoil.html
oppure contattatemi tramite E-mail: tennerie@cds.unina.it

NVFoil: Aerodynamic 2-D problem solver

Installation of NVFoil 1.01

1) Copy nvfoil.zip in a temporary folder, e.g.: c:\temp
2) Expand nvfoil.zip with utility such as pkunzip, winzip, swunzip, etc.
3) From File Manager run setup.exe and follow its instructions
4) At the end of the installation, you should also find in the "airfoil"
folder the UIUC airfoils database.

For further information, read NVFoil web page:
http://www.geocities.com/CapeCanaveral/Hangar/2524/nvfoilen.html
