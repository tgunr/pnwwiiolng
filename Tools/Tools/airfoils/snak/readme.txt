WHAT IS SNACK?=================================
-----------------------------------------------
SNACK is a shareware program that lets you do
almost anything with airfoils, including print-
ing them out to scale or saving them in several
formats. The best part is the Virtual Wind Tun-
nel which lets you evaluate your airfoils. If
you use it for more than 30 days, you must
register SNACK. Please see directions below.
Enjoy!


WHAT'S ON THE CDROM?===========================
-----------------------------------------------
On this CDROM are many files. In the root
directory, you will find all the necessary
files for installing SNACK, the Super Numerical
Airfoil Creation Kit. Run SETUP.EXE to install
SNACK.

In the PeopleMeeter directory, you will find the
files necessary for installing DreeseCode
Softwares new organizational tool, PeopleMeeter.

In the Archive directory, you will find the
almost 1200 airfoil coordinate files that come
from the University of Illinois Urbana-Champaign.
Since these files can be downloaded freely by
anybody, they are provided on the CDROM for
convenience only.  The archive is maintained by
Dr. Michael Selig and can be found on the web at:
http://amber.aae.uiuc.edu/~m_selig/ads.html
