What is ModelFoil?
ModelFoil is the airfoil analysis and design software package for Windows 95/98/NT that enables you to build better model airplane wings. ModelFoil will read-in any model airplane airfoil and generates the lift, drag, moment coefficients and other airfoil information that you will need for model airplane design and construction. Use this data to optimize your aircraft wing design. Choose airfoils that will win competitions in weight lifting, speed and endurance flying.  Airplane manufactures use expensive software similar to ModelFoil to design and analyze their airplane wings. ModelFoil brings this capability to the model airplane designer at an affordable price.


Uses of ModelFoil
ModelFoil can be used by anyone who wishes to design, analyze and construct wings for model airplanes. The software allows you to analyze an airfoil, export the shape to a .dxf file and plot the airfoil using any Windows supported printer. You can also modify the thickness and camber of your airfoil to tweak out the perfect design. In short, ModelFoil allows you to design and plot an airfoil based on aerodynamics performance for about the same cost of airfoil plotting software. Please click here for an example of how ModelFoil can be used to design your wing.

Built-in Airfoils
In addition to entering your own custom airfoils, ModelFoil comes with over 1100 built-in airfoils from the UIUC airfoil database. It also has tools to create NACA 4 and 5 digit airfoils.

Accurate Results
ModelFoil generates airfoil data using numerical techniques to solve the aerodynamics equations. The program was developed by Patrick Hanley, Ph.D., a graduate of Massachusetts Institute of Technology (MIT) department of Aeronautics and Astronautics. Unlike comparable software on the market, ModelFoil estimates the behavior of airfoil just before stall. The software is also able to warn you when your airfoil is approaching stall.

Systems Requirements
ModelFoil requires Windows 95/98/NT to operate. A 80486 based computer is the minimum requirement for the processor. A Pentium processor is ideal.
