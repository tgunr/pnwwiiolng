Development Environments
------------------------

Anything required for building a new development machine should be checked in here,
so that any given build can be more easily recreated.

WINDOWS:
	Nothing yet.

MAC:
	Nothing yet, but Vagrant is capable of bringing up Mac boxes it should be possible
	to automate Mac builds and unit tests.

LINUX:
	bootstrap.sh or bootstrap.bat will configure and provision a complete Linux virtual
	dev box using Vagrant (www.vagrantup.com) and VirtualBox (www.virtualbox.org).
