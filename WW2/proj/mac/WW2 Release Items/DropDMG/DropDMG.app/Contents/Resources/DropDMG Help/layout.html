5.1.5   Layout

If you select a layout, DropDMG will use it to set the view options, background picture, and icon positions of the mounted disk image.

You can create layouts using the Layouts tab of the Preferences window.

DropDMG ignores the Layout option when creating a disk image by converting.

Tip: Hold down the Option key when choosing a layout to open it for editing.
