4.1.1   About DropDMG

The About DropDMG window shows the credits, as well as download and support information.

You can always download the latest version of DropDMG from the DropDMG Web site.

Questions about DropDMG may be sent to dropdmg@c-command.com. We’re always looking to improve DropDMG, so please feel free to send any feature requests to that address.

To make sure that you have the latest version of DropDMG, you can use the Software Update… command.
